# Roadmap

## V0 — foundation/demo
Contrats, design system, map demo, veille demo, diagnostic demo.

## V1 — météo scientifique
Ingestion réelle, climatologie, moteur versionné, PostGIS, 5–10 productions pilotes, provenance complète.

## V1.5 — exposition
RPG/occupation, surfaces et agrégations territoriales.

## V2 — télédétection & prévision
Sentinel, prévision météo, comparaison observation/prévision, nouveaux indicateurs.

## V3 — intelligence territoriale
Personnalisation, abonnements/signaux, API partenaires, catalogues élargis, analyses inter-filières.
