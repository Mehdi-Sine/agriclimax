# Task 05 — Product Shell Design System

**Branche :** `codex/05-product-design`

## Objectif
Implémenter l'identité AgriclimaX et le shell responsive avant de construire les vues métier.

## Scope
- centraliser BRAND ;
- design tokens light/dark ;
- composants primitives ;
- wordmark/symbol/app icon SVG originaux selon brief (sans asset non licencié) ;
- shell Observation/Veille/Diagnostic ;
- desktop/tablet/mobile compositions ;
- manifest/favicon/PWA metadata si pertinent ;
- Storybook seulement si justifié, sinon route interne dev de catalogue composants ;
- docs design mises à jour.

## Règles communes
Lire `AGENTS.md` et la documentation liée. Ne pas modifier `contracts/` sans procédure. Travailler sur la branche indiquée. Ajouter tests et documentation. À la fin : commandes exécutées, résultats, fichiers modifiés, risques/limites, résumé PR.

## Critères d'acceptation
- aucune couleur métier hardcodée hors tokens ;
- WCAG AA contrôlé ;
- clavier/focus ;
- reduced motion ;
- screenshots 1440x900, 1024x768, 390x844 ;
- logo lisible petit format.
