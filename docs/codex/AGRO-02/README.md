# AGRO-02 — moteur agroclimatique multi-productions

Livraison additive et non déployée : registre déclaratif versionné, calculs
mutualisés pour blé tendre, bovins, maïs, vigne, prairies/fourrages et contrat
générique vergers. Les faits éditoriaux sont prêts pour JOUR-02 ; aucun branchement
sur le Journal quotidien ou modification d’interface.

Les indicateurs restent descriptifs et exploratoires. Les périodes incomplètes,
ruptures de modèle/support et absences d’humidité restent indisponibles avec motif.
Les portions renseignées sont conservées séparément sans extrapolation. Les
713 identités territoriales ne sont jamais filtrées à cause d’une valeur absente.
Aucun stade, dommage, rendement, stress animal ni pousse fourragère n’est déduit.
