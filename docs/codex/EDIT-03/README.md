**GO pour la revue en simulation ; NO-GO pour l'activation quotidienne.**
Les pondérations, barèmes et arbitrages IA nécessitent une validation éditoriale.
Le comité est testé avec un fournisseur injecté et un contrôle déterministe,
sans appel réel ; aucune amélioration de qualité du modèle n'est prétendue.
La petite taille de l'échantillon et l'absence de fenêtres temporelles homologues
limitent la comparaison. Le coût supplémentaire réel est nul ; les scénarios
fournisseur sont des bornes, pas un reçu ni un devis actuel.

Aucun fichier de production existant n'est modifié. Aucune acquisition, agrégation,
règle scientifique, donnée gelée, archive historique, contrat, publication,
configuration quotidienne ou interface n'est changé. Le nouveau code ne reçoit
aucun appel du Journal. La PR reste draft et sa fusion automatique n'est pas activée.
