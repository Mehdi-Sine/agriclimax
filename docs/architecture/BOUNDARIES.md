# Frontières de responsabilité

| Domaine | Possède | Ne possède pas |
|---|---|---|
| Engine | formules, indicateurs, règles | couleurs, layout, auth |
| Config | paramètres versionnés, statuts scientifiques | code UI |
| Contracts | formes de données inter-domaines | implémentations |
| Ingestion | acquisition/normalisation | interprétation visuelle |
| DB/API | persistance, sécurité, requêtes | seuils scientifiques |
| Web core | routing, état URL, sessions | formules scientifiques |
| Observation | carte/légendes/interaction | génération IA |
| Veille | signaux/provenance/narration | calcul des indicateurs |
| Diagnostic | explicabilité scientifique | modification des règles |
| Design system | présentation/accessibilité | classification du risque |
