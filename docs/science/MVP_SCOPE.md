# Périmètre scientifique MVP

Le MVP doit démontrer l'architecture sans prétendre valider toutes les productions.

## Indicateurs génériques prioritaires
- températures min/max/moyennes ;
- degrés-jours ;
- jours/heures sous seuil de froid ;
- jours/heures au-dessus d'un seuil de chaleur ;
- épisodes consécutifs ;
- cumul de précipitations ;
- P - ET0 ;
- percentile/anomalie climatologique ;
- THI élevage ;
- fraîcheur/complétude des données.

## Productions de démonstration
Blé tendre, maïs grain, colza, tournesol, vigne, pommier, prairie, bovin lait, bovin viande.

Les valeurs incluses dans `fixtures/` sont fictives. Les règles dans `config/` restent `exploratory` jusqu'à revue scientifique.
