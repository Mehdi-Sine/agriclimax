# Fixtures météo fictives

Ces valeurs sont **fictives**, non validées scientifiquement, sans fournisseur réel.
Le provider impose `source_id=demo-weather` et `demo=true` dans chaque provenance.
Seule la date 2025-01-01 existe ; toute autre date est explicitement `missing`.
Le `published_at` de l'enveloppe synthétique d'absence est le début de sa date UTC,
pas une prétendue publication d'un fournisseur réel.
